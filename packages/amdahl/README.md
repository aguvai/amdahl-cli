# amdahl

The short name for [`@amdahl/cli`](https://www.npmjs.com/package/@amdahl/cli),
the `amdahl` command line. These two commands do the same thing:

```sh
npx amdahl skills add amdahl/system-diagram
npx @amdahl/cli skills add amdahl/system-diagram
```

This package holds no code of its own. Its `amdahl` command loads
`@amdahl/cli` at the same version, its only dependency. Docs, source and
issues: https://github.com/amdahlco/amdahl-cli
